\section{Conclusion}
\label{sec:conclusion}

This paper has shown that FPGAs can accelerate time series classification using MiniRocket and Hydra in both single-node and network streaming contexts, with accelerator accuracy matching the reference CPU implementation within 0.01\% on all benchmark datasets. MiniRocket's fused CONV+PPV kernel achieves 8.5--58.7$\times$ speedup over an optimized C++ baseline using up to three compute units. Compared to a Tesla T4 GPU, the 3-CU FPGA exceeds batch-size-one throughput on all evaluated datasets while consuming 2.1--2.6$\times$ less power, with sub-0.5\,ms mean latency across all datasets. An on-chip dataflow decomposition of the Hydra kernel via AXI-Stream interfaces preserves bit-exact accuracy, confirming that the architecture is amenable to modular partitioning. In a network streaming experiment, the FPGA SmartNIC achieves 1.37$\times$ lower RTT than a DPDK-optimized CPU baseline. Multi-FPGA scaling via 100G Ethernet is under active investigation.
