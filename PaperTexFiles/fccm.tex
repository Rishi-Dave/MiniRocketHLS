\begin{abstract}
This paper presents FPGA accelerator architectures for two time series classification algorithms, MiniRocket and Hydra, both of which employ convolutional kernels to generate features for downstream classifiers. Prior work has established that a combined MultiRocket+Hydra classifier is competitive with the state of the art in this domain; our accelerators match reference CPU accuracy within 0.01\% on all benchmark datasets. In single-node evaluation, MiniRocket achieves 8.5--58.7$\times$ speedup over an optimized C++ baseline with three compute units; at batch-size-one inference, the 3-CU FPGA exceeds a Tesla T4 GPU on all evaluated datasets for both algorithms while consuming 25.7\,W vs.\ 54--68\,W. We additionally evaluate an on-chip dataflow decomposition for Hydra via AXI-Stream interfaces, demonstrating that its 512-kernel architecture can be partitioned into independently synthesized sub-kernels while preserving bit-exact accuracy. In a separate network streaming experiment, the FPGA configured as a SmartNIC achieves 1.37$\times$ lower round-trip time than a DPDK-optimized CPU baseline. These results demonstrate how and when FPGAs retain an advantage over CPUs and GPUs for processing streaming time series data in real time.
\end{abstract}
